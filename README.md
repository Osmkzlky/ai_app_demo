# 🤖 AI APP Demo – Flutter + GetX + Yapay Zeka

Flutter ve GetX kullanarak geliştirdiğim bu projede; görsel oluşturma, sohbet botu ve çeviri özelliklerini bir araya getirdim.  
Modern yapısıyla kullanıcıların yapay zekâ destekli deneyimlere ulaşmasını sağlayan güçlü bir mobil uygulamadır.

---

## 📁 Proje Yapısı

```plaintext
lib/
├── apis/                     # OpenAI, Unsplash ve Google Translate API işlemleri
├── controller/               # Sayfa controller'ları
├── helpers/                  # Yardımcı fonksiyonlar
├── model/                    # Veri modelleri
├── screen/                   # Tüm sayfalar (home, chat, translator vs.)
├── widgets/                  # Özel bileşenler
└── main.dart                 # Uygulamanın giriş noktası
```

---

## 🚀 Kurulum ve Çalıştırma

### 1. Flutter bağımlılıklarını yükle:
```bash
flutter pub get
```

### 2. API Anahtarlarını ekleyin:
- OpenAI, Unsplash ve Google Translate API anahtarlarınızı `lib/apis/` altındaki ilgili dosyalara yerleştirin.
- API anahtarlarını .env veya sabitler dosyası ile güvenli şekilde yönetin.

### 3. Uygulamayı çalıştır:
```bash
flutter run
```
